## Mill handoff

`package_append.py package.json` validates sealed plan/render status/tail hash,
packet-copies only the short retained overlap plus `tail.mkv`, and produces:

- `RUN/package/ledger/segments.json`
- `RUN/package/package_verified.json`

Its specification is exactly `preparedManifest`, `previousManifest`,
`previousSHA256`, `oldInit`, `destination`, and `segmentFrames: 600`.

Library boundary: `fragment_manifest.plan_tail(previous, join_frame=JOIN,
segment_frames=600, fps_num=60)` returns `retainedCount`, `packageStartFrame`,
`oldTailFrames`, `offsetTicks`, and `firstSequence`.
`replace_tail(fresh_root, previous_path, expected_parent_sha256, retained_count,
fragments=[(bytes, durationTicks)], rebase_to_boundary=True)` creates the ledger.

The final stage uses the new CLI:

```
publish_append.py prepare SOURCE DEST --object-prefix PREFIX \
  --previous PREVIOUS_SEGMENTS_JSON --previous-sha256 RAW_SHA256
```

An optional `--execution-manifest /absolute/file.json` may accompany **prepare**.
This example deliberately omits it and contains no `execute`, rollback, upload,
deploy, historical publisher, or release-pointer command. Production publication
is unverified and remains parent-owned.

## Timing and verification

Progress JSONL contains PIDs, elapsed seconds, latest renderer block, FFmpeg
frame/fps/speed, phase and phase-specific ETA when a rate is available. Replay ETA
is not an estimate for the entire pipeline. Polls read only bounded log tails.

with `-xerror`; the final decoder progress frame count must match `tailFrames`.
Packet-gate and single-decode durations are reported separately.
